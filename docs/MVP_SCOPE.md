# Phase 1 MVP scope

Phase 1 supports manual business/contact entry, manual opportunities, deterministic local call briefs, manual `tel:` handoff, human-recorded outcomes, and follow-up tasks.

The implemented browser flow includes business details, contact editing, opportunity entry, call-brief editing/readiness, backend-authorized manual-call confirmation, outcome recording, global call history, task status updates, and dashboard projections.

It excludes automated calls, recording/transcription, scraping, external AI, paid data or messaging, cloud credentials, multi-tenancy, billing, complex authorization, and remote deployment. Authentication must be added before any remote deployment.
